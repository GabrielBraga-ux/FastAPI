# 🎬 API de Filmes com FastAPI

Projeto acadêmico desenvolvido para criar uma **API de filmes utilizando FastAPI**, com documentação interativa através do **Swagger**.

A aplicação utiliza dados de filmes e disponibiliza endpoints para consulta e manipulação das informações por meio de uma API REST.

## 🚀 Tecnologias utilizadas

* Python
* FastAPI
* Swagger / OpenAPI
* Pandas
* Scikit-learn
* Uvicorn
* Jinja2

## 📂 Projeto

A API utiliza dados de filmes para disponibilizar informações de forma estruturada através de endpoints.

O **Swagger** permite visualizar e testar os endpoints diretamente pelo navegador, facilitando a utilização e validação da API.

## ⚙️ Instalação

Instale as dependências utilizadas no projeto:

```bash
pip install scikit-learn fastapi pandas uvicorn jinja2
```

## ▶️ Execução

Para executar a API, utilize o Uvicorn:

```bash
uvicorn main:app --reload
```

Após iniciar a aplicação, a documentação interativa do Swagger pode ser acessada em:

```text
/docs
```

## 🎯 Objetivo

O objetivo do projeto é desenvolver uma **API REST para dados de filmes**, aplicando conceitos de desenvolvimento de APIs, processamento de dados e documentação de serviços utilizando FastAPI e Swagger.

## 🎓 Projeto Acadêmico

Projeto desenvolvido como atividade acadêmica, com foco na criação e disponibilização de uma API utilizando **FastAPI e Swagger**.
